# 우드 스크류 마스터 (Wood Screw Master)

나사를 옮겨 겹쳐진 나무판을 모두 떨어뜨리는 원목 공방 테마의 물리 퍼즐입니다.
**바로 플레이: https://llutar-design.github.io/wood-screw-master/**

서버나 설치 없이 `index.html`을 브라우저로 열어도 바로 실행됩니다. 필요한 라이브러리(Matter.js 0.20)는 `vendor/`에 들어 있고 외부 네트워크를 쓰지 않습니다.

## 플레이 방법

1. 나사를 누르면 선택되고, 옮길 수 있는 빈 구멍이 빛납니다.
2. 빛나는 구멍을 누르면 나사가 옮겨집니다. 같은 나사나 빈 곳을 누르면 취소됩니다.
3. 나사가 하나 남은 판자는 그 나사를 축으로 돌고, 나사가 모두 빠진 판자는 떨어집니다.
4. 모든 판자를 화면 아래로 떨어뜨리면 클리어입니다.

이동 제한을 넘기거나 옮길 수 있는 수가 없으면 실패합니다. 이동 횟수에 따라 별을 1~3개 받습니다.

### 규칙의 세부

- 나사는 빈 구멍으로만 옮길 수 있습니다. 구멍 위에 그 자리에 구멍이 없는 판자가 있으면 몸통이 관통하므로 막힙니다.
- 옮긴 자리에 판자 구멍이 맞물려 있으면 그 판자를 고정합니다. 맞물린 판자가 없으면 배경에만 박힙니다.
- 나사 머리가 위층 판자에 덮이면 집을 수 없습니다.
- 같은 층의 판자끼리는 충돌합니다. 다른 층은 앞뒤로 떨어져 있어 겹칠 수 있습니다.
- 나사 몸통은 머리 높이까지의 층을 가로지릅니다. 그래서 낮은 층의 판자는 나사에 걸립니다.
- 되돌리기를 쓰면 이동 횟수도 함께 되돌아갑니다.
- 힌트는 정답 수순에 있으면 다음 수를 보여 주고, 벗어나면 현재 상태에서 다시 탐색합니다. 답을 찾지 못하면 되돌리기나 재시작을 안내합니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html`, `style.css` | 화면 구조와 메뉴·HUD 스타일 |
| `game.js` | 입력, 렌더링, 진행, 저장, 힌트 UI |
| `physics.js` | Matter.js 월드, 나사·구멍 규칙, 정답 탐색기 |
| `levels.js` | 30개 스테이지 데이터 (생성물) |
| `audio.js` | Web Audio로 합성한 효과음 |
| `vendor/matter.min.js` | 물리엔진 (MIT, `vendor/matter.LICENSE.txt`) |
| `tools/build_levels.js` | 레벨 제작 도구 (실행에는 불필요) |
| `tests/` | 자동 검증 스크립트 (실행에는 불필요) |

저장은 브라우저 `localStorage`의 `wood-screw-master.save.v1` 키에 해금 단계, 별, 최고 기록, 소리 설정으로 기록됩니다.

## 레벨 데이터 형식

```js
{
  levelId: 11, difficulty: "intermediate", name: "엇갈린 들보", tip: "",
  boards: [{ id: "b1", shape: "rect", w: 308, h: 68, x: 360, y: 510, angle: 0,
             mass: 2.3, layer: 1, wood: "oak", holes: [{ x: -120, y: 0 }] }],
             // shape: "poly"이면 w, h 대신 points: [[x, y], ...]
  holes:  [{ id: "h1", x: 240, y: 510 }],        // 벽의 구멍
  screws: [{ id: "s1", holeId: "h1", metal: "brass" }],
  moveLimit: 9, targetMoves: 6,
  solution: [{ screw: "s1", from: "h1", to: "h5" }]
}
```

판자의 `holes`는 판자 중심 기준 좌표이고, `layer`는 1이 가장 뒤쪽입니다.

## 물리 설계

- 고정 스텝(1/60초)으로 진행하고, 판자가 모두 멈춘 뒤에만 다음 이동을 확정합니다.
- 이동을 확정할 때마다 반올림한 스냅샷으로 엔진을 다시 만듭니다. 같은 상태에서 같은 수를 두면 결과가 같아서 검증기, 힌트, 실제 플레이가 같은 궤적을 따릅니다.
- 나사 2개 이상이면 판자를 정적 강체로, 1개면 회전축 제약으로, 0개면 자유 강체로 둡니다.
- 판자마다 충돌 카테고리 비트를 줘서 같은 층끼리, 그리고 나사 몸통과의 충돌을 제어합니다.
- 속도와 각속도에 상한을 둬서 고속 충돌 누락을 줄입니다.

## 검증

Node.js가 있으면 다음으로 다시 확인할 수 있습니다.

```
node tests/verify_levels.js   # 30개 정답 재생, 좌표 섭동, 규칙, 이탈 힌트
npm i puppeteer-core          # 아래 시험에만 필요
node tests/e2e.js             # Chrome 실제 터치 입력으로 전 과정과 30단계 클리어
```

레벨을 다시 만들려면 `node tools/build_levels.js pool`, `refine`, `write` 순서로 실행합니다.
